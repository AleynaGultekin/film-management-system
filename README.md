# 🎬 Film Management System (Java)

A high-performance Java desktop simulation developed as a coursework project utilizing custom data structures for film analytics, ranking algorithms, and search operations.

## 📌 Project Overview
This project avoids default built-in Java collection frameworks where required to demonstrate the low-level mechanics of custom data structures. It efficiently manages movie records, box-office revenue statistics, and user search queries.

## 🛠️ Data Structures Implemented
- **Linked Lists & Queues:** Managing sequential movie entries and processing queues.
- **Stacks & Hash Tables:** Fast attribute lookup and state tracking.
- **Heaps & Binary Search Trees (BST):** Optimized film ranking algorithms and logarithmic time search operations.

## 🚀 Key Features
- Dynamic film ranking and sorting based on ratings and box-office revenue.
- Efficient search and filtering operations powered by custom BST / Hash Table logic.
- Simulated box-office operations and financial performance reports.

## 💻 Tech Stack
- **Language:** Java
- **Concepts:** Custom Data Structures, Algorithm Design & Optimization
